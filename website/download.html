Before you install

  • Windows 10 (build 17763 / version 1809) or later — needed for the media-session API this app reads "now playing" info from.
  • No admin rights needed — the installer installs for your user account only.
  • Optional: NDI Runtime — only needed if you turn on the Network Feed option to broadcast the display over your LAN.
