Features

Built for a second screen, a stream, or a stage

Everything it does is aimed at one job: showing what's playing, clearly, on a screen other than your own.

🖥️

Works with everything already playing

Reads Windows' built-in media session, so it works automatically with Spotify, browsers, Windows Media Player, VLC, iTunes, and anything else that reports "now playing" — no per-app setup.

🎨

Three layouts

Centered, or album art hugging the left or right edge with an animated equalizer visualization filling the rest of the screen. Switching layouts fades smoothly instead of snapping.

🎤

Synced lyrics

Optionally shows the current line of lyrics, karaoke-style, synced to playback position — looked up automatically, no manual entry.

🕐

Clock overlay

An optional live time and date display for the album-left/right layouts, sized and aligned to match the rest of the screen.

📡

NDI network feed

Broadcast the display over your network as an NDI source — pick it up in EasyWorship (via NDI Virtual Input) or any other NDI-aware software on another computer.

🎚️

Playback & volume controls

Previous, play/pause, and next send commands straight to whatever's playing, and a slider controls the system's master volume — right from the control panel.

🖼️

Preview without going fullscreen

A windowed preview shows exactly what the display would look like, live, so you can check a layout before putting it on a real screen.

🌙

Blank screen & tray icon

Temporarily blank the display without closing it, and let the app live quietly in the system tray, starting with Windows if you want it always ready.

🆓

Free and open source

No account, no subscription, no telemetry. The full source is on GitHub if you want to see how it works or change something yourself.

How it works

Up and running in under a minute

No setup inside the apps you're already using — Music Display just reads what Windows already knows is playing.

Install and launch

Download the installer, run it — no admin rights needed — and the control panel opens automatically.

Pick a monitor and layout

Choose which screen it should appear on and a layout, then click Preview if you want to check it first.

Show the display

Click Show Display and start playing something anywhere on your PC — the screen updates automatically as tracks change.
